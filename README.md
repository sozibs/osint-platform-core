Professional OSINT Intelligence Platform — Digital Footprint, Investigation, Cyber OSINT, and Misinformation Analysis.

## Install as an App

| Platform | Instructions |
|---|---|
| Android | Open in Chrome → tap "Install" banner |
| iOS | Open in Safari → Share → "Add to Home Screen" |
| Desktop | Open in Chrome/Edge → click ⊕ in address bar |

See [PWA_GUIDE.md](./PWA_GUIDE.md) for full installation instructions.

## Features

- ✅ Progressive Web App (installable on all platforms)
- ✅ Offline support with service worker caching
- ✅ Background sync for offline action queuing
- ✅ Push notifications for investigation updates
- ✅ Responsive UI (mobile / tablet / desktop)
- ✅ Touch gesture support
- ✅ Bottom navigation on mobile
- ✅ FastAPI backend with 12-layer architecture
- ✅ Plugin system for OSINT modules

## Quick Start

```bash
git clone https://github.com/sozibs/osint-platform-core.git
cd osint-platform-core
docker compose up -d
# Open http://localhost
```

See [INSTALLATION_GUIDE.md](./INSTALLATION_GUIDE.md) for full setup instructions.
